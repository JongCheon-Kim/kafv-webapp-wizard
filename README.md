# KAFV AI 웹앱 제작 마법사

**KAFV AI WebApp Wizard | No-Code Web Application Builder**

한국어촌가치연구소(KAFV)에서 개발한 교육·실습용 노코드 웹앱 제작 도구입니다.

코딩 경험이 없는 교수자, 대학생, 일반인도 웹앱의 화면과 기능을 시각적으로 구성하고, 데이터를 연결하여 독립 실행형 HTML 웹앱을 제작할 수 있도록 설계되었습니다.

본 도구는 단순히 웹앱을 만드는 것을 넘어, **UI·UX와 기능 구조를 이해하고 AI에게 원하는 앱의 설계 요구사항을 정확하게 전달할 수 있는 능력**을 기르는 것을 목적으로 합니다.

## 🧩 주요 기능

### 1. 웹앱 시작 틀 선택

- 9개 시작 유형 제공
- 목적에 맞는 웹앱 기본 구조 선택
- 기존 시작 틀을 활용한 앱 제작
- 빈 화면에서 자유롭게 웹앱 구성

### 2. UI·UX 시각적 구성

- 34종의 UI·UX 부품 제공
- 화면 구성요소 추가·이동·삭제
- 제목, 설명, 입력창, 선택 도구 등 구성
- 카드, 표, 그래프 등 정보 표현
- 부품별 속성 및 디자인 설정
- 편집 화면에서 앱 구성 확인

### 3. 데이터 활용

- CSV·JSON·TXT 등 실습 데이터 활용
- 데이터와 UI 구성요소 연결
- 표와 정보카드 등으로 데이터 표현
- 업로드한 데이터를 활용한 앱 기능 구성

※ 데이터 형식과 부품에 따라 지원되는 연결·처리 기능은 다를 수 있습니다.

### 4. 웹앱 실행 및 검증

- 제작 중 화면 미리보기
- 편집 모드와 실제 작동 확인
- PC·모바일 화면 구성 확인
- 입력 및 기능 버튼의 작동 테스트
- 구성요소와 데이터 표시 결과 검증

### 5. 독립 HTML 웹앱 제작

- 작동하는 독립 HTML 파일 생성
- HTML·CSS·JavaScript 기반 실행
- 생성된 파일의 브라우저 실행
- 반응형 화면 구성
- PC·모바일 보기 전환 옵션
- GitHub Pages 등 정적 웹 호스팅을 활용한 공개 가능

※ 모바일 보기 기능은 화면 폭과 반응형 배치를 확인하는 도구이며, 실제 모바일 기기의 완전한 에뮬레이터는 아닙니다.
